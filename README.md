## `$ whoami`

I'm a **software developer and Computer Engineering student** interested in building useful products and understanding the technology underneath the abstractions I use every day.

I started with the web — HTML, CSS and JavaScript — and gradually moved into application development, backend systems, databases and product architecture.

I'm still learning a lot, and that's intentional.

I don't want to only know *how to use* a technology.

I want to eventually understand **why it works, what happens underneath it, and whether I can build a simpler version myself.**

That's what drives many of the projects I experiment with.

## `$ selected_experiments`

Not everything I build is intended to become a product.

Some projects start with a simple question.

### 🧹 Developer Tooling

What started as a small script to remove `console.log()` statements from production code became a much bigger question:

> **What if developer cleanup and workflow automation could be handled systematically across different languages and projects?**

I'm exploring where that idea can go — from simple JavaScript tooling toward broader developer automation.

---

### 🎨 Block AI

An early exploration around turning visual interface designs into usable code.

The bigger idea is to explore the relationship between:

**Design → Structure → Code → Responsive interfaces**

The long-term question:

> **Can the design itself become the source of truth for the application?**

> **Status:** Experimental

---

### ⚙️ Nomos

An early SDK/platform concept exploring reusable backend infrastructure and services that developers could plug into their applications instead of repeatedly building the same foundations from scratch.

Areas explored include:

* validation
* security
* integrity
* AI services
* financial infrastructure
* reusable backend services

> **Status:** Experimental / On hold
